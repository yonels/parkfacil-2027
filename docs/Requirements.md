# Requirements

## Objetivo
Definir los requerimientos iniciales para la fundación del proyecto ParkFacil 2027.

## Requisitos autorizados
- Next.js App Router
- JavaScript
- Tailwind CSS
- ESLint
- `src` directory
- alias `@/*`
- npm
- Git
- GitHub CLI para verificar autenticación
- Supabase CLI para verificar autenticación

## Restricciones
- No usar TypeScript
- No instalar librerías adicionales sin autorización
- No modificar ni crear archivos fuera de `C:\proyectos\parkfacil-2027`
- No crear repositorio remoto en GitHub sin autorización
- No crear proyecto remoto en Supabase
- No crear tablas ni migraciones reales
- No usar Supabase para la Biblioteca Documental
- No desarrollar funcionalidad de negocio ni módulos operacionales
