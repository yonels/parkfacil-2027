# Identidad visual de ParkFacil

## Color corporativo principal

- Nombre: Azul corporativo ParkFacil
- HEX: `#3150D8`
- RGB: `49, 80, 216`
- Variable CSS oficial: `--pf-color-brand-primary`
- Token Tailwind: `brand-primary`

Este color fue confirmado como referencia corporativa el 31 de julio de 2026.
Debe utilizarse como color principal en botones, enlaces, estados seleccionados,
encabezados y elementos de identificación de marca.

No se deben introducir nuevos tonos azules principales directamente en los
componentes. Las variantes oscuras, bordes y sombras deben derivarse de los
tokens definidos en `src/app/globals.css`.

## Colores complementarios vigentes

- Azul profundo: `#041E42`
- Fondo azul claro: `#EEF4FF`
- Borde azul claro: `#BFD2FF`
- Blanco: `#FFFFFF`

Los colores verde, rojo y ámbar quedan reservados para estados operacionales:
ingreso o éxito, salida o error, y advertencia o lectura QR, respectivamente.
